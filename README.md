# Snake Game in C++

A console-based Snake Game developed using C++ and Windows API.

## Features

* Real-time movement using W, A, S, D controls
* Random fruit generation
* Dynamic snake growth
* Score tracking system
* Wall collision detection
* Self-collision detection
* Smooth console rendering

## Technologies Used

* C++
* Windows API
* Arrays
* Functions
* Console Graphics

## Controls

| Key | Action     |
| --- | ---------- |
| W   | Move Up    |
| S   | Move Down  |
| A   | Move Left  |
| D   | Move Right |
| X   | Exit Game  |

## Learning Outcomes

* Game Loop Architecture
* Collision Detection
* Real-Time Input Handling
* Array Manipulation
* Console Rendering Techniques
